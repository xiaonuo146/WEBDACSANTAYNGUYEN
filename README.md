# Đặc Sản Tây Nguyên

Website bài tập Chương 2 + Chương 3.

## Cấu trúc
- index.html: Trang chủ
- products.html: Danh sách sản phẩm + tìm kiếm/lọc + thêm giỏ hàng bằng JavaScript
- product-detail.html: Chi tiết sản phẩm + sản phẩm liên quan
- contact.html: Liên hệ + form đặt hàng và validation client
- css/style.css: CSS dùng chung, mobile-first, Flexbox, Grid, transition, animation
- js/main.js: dữ liệu sản phẩm, DOM render, tìm kiếm, lọc, giỏ hàng, validation
- images/: ảnh minh họa cục bộ

## Chạy
Mở thư mục bằng VS Code và chạy Live Server từ file index.html.
